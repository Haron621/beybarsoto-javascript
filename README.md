# Beybars Oto Servis — JavaScript

[English](#english) · [Türkçe](#türkçe)

## English

A lightweight multilingual website for Beybars Oto Servis in Kestel, Alanya, built with HTML, CSS, and vanilla JavaScript. The website is available in Turkish, English, and Russian and includes service information, contact details, directions, and WhatsApp links.

### Run locally

Open `index.html` directly in a web browser. Node.js and package installation are not required.

### Project files

- `index.html` — page structure, styles, translations, and JavaScript behavior
- `logo.jpg`, `logo_1.jpg`, `logo_3.jpg` — website images
- `instagram-logo.png` — Instagram image asset
- `CNAME` — custom-domain configuration

### Deployment

Upload the project files to any static hosting service, such as AWS Amplify, GitHub Pages, Cloudflare Pages, or Netlify.

## Türkçe

Kestel, Alanya'daki Beybars Oto Servis için HTML, CSS ve saf JavaScript ile geliştirilmiş hafif ve çok dilli web sitesi. Site Türkçe, İngilizce ve Rusça dillerinde hizmet bilgileri, iletişim bilgileri, yol tarifi ve WhatsApp bağlantıları sunar.

### Yerel olarak çalıştırma

`index.html` dosyasını doğrudan bir web tarayıcısında açın. Node.js kurulumuna veya paket yüklemeye gerek yoktur.

### Proje dosyaları

- `index.html` — sayfa yapısı, stiller, çeviriler ve JavaScript işlevleri
- `logo.jpg`, `logo_1.jpg`, `logo_3.jpg` — web sitesi görselleri
- `instagram-logo.png` — Instagram görseli
- `CNAME` — özel alan adı yapılandırması

### Yayınlama

Proje dosyalarını AWS Amplify, GitHub Pages, Cloudflare Pages veya Netlify gibi herhangi bir statik barındırma hizmetine yükleyebilirsiniz.
